# Documentation history

Before 0.29.3, manuals accumulated release-specific testing instructions and superseded descriptions. The current tree keeps topic-based user guides and developer references. Internal work plans, package handoff notes and obsolete testing checklists were removed from the distributed source tree. Their previously published versions remain available in Git history; this cleanup does not rewrite commits or remove software version history.

[CHANGELOG.md](../../CHANGELOG.md) records feature changes. [Windows acceptance](../development/WINDOWS_ACCEPTANCE.md) records the reported native testing baseline and outstanding checks. Current test/build procedures live in [TESTING.md](../development/TESTING.md) and [WINDOWS_INSTALLER.md](../development/WINDOWS_INSTALLER.md).
